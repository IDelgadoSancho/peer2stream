# Peer2Stream

Peer2Stream is a web application developed to allow users to discover, watch, and organize their favorite movies and series in a simple and attractive way.

---

## 🛠️ Technologies Used

- **Frontend:** React, Next.js, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Authentication:** JWT
- **Other tools:** TMDB API, Vercel for deployment

## 💼 My Contribution

During the development of Peer2Stream, my responsibilities included:

### Backend
- Configuration and development of the REST API using Node.js and Express.
- Implementation of user authentication and authorization using JWT.
- Design and management of the MongoDB database, including the creation of models and schemas.

### Frontend
- Integration of the TMDB API to obtain information about movies and series.
- Development of key React components for content visualization.
- Implementation of the "videoclub" functionality so users can save and organize their favorite content.

### Deployment
- Configuration and deployment of the application on Vercel to facilitate access and testing.
